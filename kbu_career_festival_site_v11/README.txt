- Hero 일정: 2026. 10. 07. (수) 10:00–17:00. 이미지 대체텍스트도 같은 일정으로 변경했습니다.
- 이미지 파일명: assets/hero-banner-v12.png (이전 이미지 캐시와 혼동 방지)
- 모든 페이지의 PC 헤더·모바일 메뉴에서 행사소개 링크를 제거했습니다.
- 홈 퀵메뉴에서 행사안내를 제거하고 프로그램 / 채용정보 두 항목만 유지했습니다.

- 모든 페이지의 헤더 및 모바일 고정 참가신청 버튼, 홈 하단 참가신청 버튼을 아래 주소에 직접 연결했습니다.
  https://eastpeace.kr/conference-register.html?code=6960b8ce
- 링크는 현재 탭에서 열립니다. 빈 내부 신청 페이지를 거치지 않습니다.

유지 사항
- Hero 프레임 크기, 여백, 둥근 모서리, 그림자, 이미지 비율을 유지했습니다.
- 일반 스크롤이며 헤더는 스크롤하면 화면 밖으로 사라집니다.
- 모바일 고정 참가신청 버튼은 기존 위치와 크기를 유지했습니다.
- 홈 순서: Hero → 참여기업 → 퀵메뉴 → 참가신청 → 최소 Footer.
- 참여기업 로고, 행사 세부 프로그램 등 보류 중인 자료는 이번에 추가하지 않았습니다.
- 프로그램 / 참여기업 / 채용정보 하위 페이지 본문은 비워두었습니다.
- 공지사항이나 삭제한 Footer의 부서명을 다시 추가하지 않았습니다.
- about/index.html 및 apply/index.html의 빈 파일은 기존 파일 호환성을 위해 보존하되, 현재 메뉴에서는 연결하지 않습니다.

열어보기
1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. 그 폴더의 index.html을 엽니다.
3. 웹 서버에 배포할 때는 폴더 안의 파일 전체를 함께 업로드합니다.
4. 사전등록 사이트와 외부 글꼴을 불러오려면 인터넷 연결이 필요합니다.

이 파일에는 실제 접수 기능을 만들지 않았습니다. 모든 참가신청은 제공된 외부 시스템에서 진행합니다.
등록 폼의 표시 내용과 접수 가능 상태는 외부 시스템의 운영 상태에 따릅니다.
