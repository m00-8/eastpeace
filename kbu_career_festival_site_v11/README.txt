KBU Career Festival v15

주요 변경
- 홈 순서: Hero → 이벤트존/참여자혜택 2분할 → 참여기업 전체 로고 → 퀵메뉴 3개 → 참가신청 → Footer
- 홈 참여기업은 최신 엑셀 기준 33개 기업·기관만 사용, 6열·무테두리 로고 배열
- 기존 잘못된 홈 참여기업 10개와 전체보기 버튼 삭제
- 퀵메뉴에 참여기업 추가
- 참여기업 페이지: 로고/기업명/규모/지역/한 줄 소개, 비클릭 카드
- 채용정보 페이지: 로고+기업명만 표시, 클릭 시 기업별 채용정보 페이지로 이동
- 기업별 채용정보 페이지: 확인된 홈페이지 주소만 표시, 채용정보는 준비 중 유지
- 미작성/확인 필요 정보는 공란 유지
