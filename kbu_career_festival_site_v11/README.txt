KBU Career Festival v11

기준: v10 전체 웹사이트

이번 변경
- assets/hero-banner.png만 승인된 새 이미지로 교체했습니다.
- 새 이미지에는 기존 Hero의 양쪽 필기체 홍보 문구가 없습니다.
- 승인된 이미지 파일을 재편집하거나 재압축하지 않고 그대로 사용했습니다.

유지 사항
- 모든 HTML, CSS, JavaScript는 v10과 동일합니다.
- Hero의 원본 비율, 프레임 크기, 여백, 둥근 모서리, 그림자를 유지했습니다.
- Hero → 참여기업 미리보기 → 퀵메뉴 → 참가신청 → Footer 순서를 유지했습니다.
- 일반 스크롤과 스크롤 시 화면 밖으로 사라지는 헤더를 유지했습니다.
- 모바일 햄버거 메뉴와 우측 하단 고정 참가신청 버튼을 유지했습니다.
- 공지사항 페이지·메뉴 및 삭제한 Footer 부서명을 다시 추가하지 않았습니다.
- 하위 페이지의 비어 있는 본문을 유지했습니다.
- 새 행사 구성이나 미확정 기업 정보는 추가하지 않았습니다.

확인 방법
1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. 해당 폴더의 index.html을 엽니다.
3. 이전 버전의 폴더나 파일이 아닌 v11을 열었는지 확인합니다.

외부 글꼴은 기존처럼 Google Fonts에서 불러옵니다.
인터넷 연결이 없으면 기존 코드에 지정된 시스템 글꼴로 표시됩니다.
참가신청은 기존처럼 빈 apply/index.html로 연결됩니다. 실제 접수 기능은 추가하지 않았습니다.
